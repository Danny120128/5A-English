# 5A Synonym Lab — test version

Synonym revision site for 5A English, for the teacher to try out.

- Student side: Daily 10, Speed Round, Match, Paraphrase, Listen (with dictation), flashcards, mistake book, ranking and progress.
- Teacher view: class overview, each student's progress, hardest words, mastery map, class word list, CSV export.
- English / 繁體中文 interface, built for iPad.

Live site: https://danny120128.github.io/5A-English/
Teacher view directly: https://danny120128.github.io/5A-English/#teacher

This is the test version. The class in the teacher view is made up (Student 01–30). Everything is saved only in the browser that uses it; nothing is uploaded. The real version for the class will run separately.
