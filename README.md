# 5A Synonym Lab

Synonym revision site for 5A English: adaptive Daily 10, Speed Round, Match, Paraphrase, Listen (with dictation), flashcards, mistake book, ranking and progress. English / 繁體中文 interface, built for iPad.

Live site: https://danny120128.github.io/5A-English/

Progress and scores are saved in each student's own browser. Nothing is uploaded.
